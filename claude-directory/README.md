# PlaceCall for the Claude plugin directory

PlaceCall lets Claude find a US business, place a real phone call, answer questions while the call is in progress, and report the outcome and transcript. The plugin connects to PlaceCall's hosted MCP server. Sign in through the MCP connection's browser flow; no API key is required for this plugin. In Claude Code, use `/mcp` and select `placecall` if the connection asks you to sign in.

Try: “Find a florist in Chicago and ask whether they have fresh peonies today.” Review the business, number, and call brief before Claude dials. Calls are recorded and may use credits. The MCP tools do not offer recording changes, call cancellation, or call history. For those API-only features, see the [full PlaceCall documentation](https://github.com/voygr-tech/placecall). The [privacy policy](https://voygr.tech/privacy-policy/) describes data handling.
